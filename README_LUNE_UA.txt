LUNE Jewelry — навчальний вебсайт

Структура:
- index.html — головна сторінка
- products.html, about.html, blog.html, testimonial.html, contact.html — внутрішні сторінки
- css/ — стилі шаблону та css/lune.css — оформлення LUNE
- images/ — локальні зображення та логотип
- js/lune.js — меню, фільтр каталогу та демонстраційні форми

ПЕРЕД ПУБЛІКАЦІЄЮ:
1. Замініть демонстраційні контакти на власні/умовні навчальні контакти.
2. Перевірте посилання та ціни.
3. Для Google Analytics створіть GA4 property і web data stream, скопіюйте Measurement ID (G-XXXXXXXXXX), а потім додайте офіційний gtag.js snippet у <head> усіх HTML-сторінок або використайте спільний шаблон. Measurement ID навмисно не додано, оскільки його потрібно отримати у вашому обліковому записі Analytics.
4. Завантажте вміст цієї папки в корінь публічного GitHub-репозиторію та активуйте Settings → Pages → Deploy from a branch → main → /(root).

Ціни та відгуки є демонстраційними матеріалами для навчального проєкту, а контактні дані — заповнювачами.
